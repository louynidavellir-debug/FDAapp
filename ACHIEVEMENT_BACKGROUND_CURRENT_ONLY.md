# Fundos por conquista — regra atual

Os planos de fundo vinculados a conquistas ficam disponíveis somente enquanto o operador possuir, naquele momento, a conquista correspondente.

- Recebeu a conquista: o fundo é liberado.
- A conquista foi retirada: o fundo é bloqueado imediatamente.
- Se o fundo retirado estava aplicado, o perfil volta para o tema padrão Asgard.
- Notificações antigas, insígnias destacadas e o campo legado `unlockedProfileBackgrounds` não concedem acesso permanente.
- A galeria usa `achievement_awards` e `completedBy` atuais como fonte de verdade.
